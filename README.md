The Samsung Galaxy J4 (codenamed _"j4lte"_) are a mid-range smartphone from Samsung.

It was announced and released in May 2018.

## Device specifications

| Device                    | Samsung Galaxy J4 2018                            |
| ------------------------: | :------------------------------------------------ |
| SoC                       | Samsung Exynos 7570                               |
| CPU                       | Quad-core 1.4 GHz Cortex-A53                      |
| GPU                       | Mali-T720                                         |
| Memory                    | 2GB / 3GB                                         |
| Shipped Android version   | 8.0                                               |
| Storage                   | 32GB eMMC 5.1 flash storage                       |
| Battery                   | Non-removable Li-Io 3000mAh                       |
| Dimensions                | 151.7 x 77.2 x 8.1 mm                             |
| Display                   | 1280 x 720 (16:9), 5.5  inch                      |
| Rear camera 1             | 13MP, f/1.9                                       |
| Front camera              | 5MP                                               |
